# tap

Official Homebrew tap for Siberia.

This repository maintains the Homebrew formulae and updater scripts used to distribute Siberia through Homebrew.

The software packaged here comes from the official Siberia GitHub releases:
<https://github.com/cavanaug/siberia>

## Install

You can install Siberia directly from this tap without adding it first:

```bash
brew install cavanaug/tap/siberia
```

If you want local access to this tap first:

```bash
brew tap cavanaug/tap
```

## Maintained Formulae

### `siberia`

Supply-chain hardening CLI for pip, uv, npm, pnpm, and Cargo lockfile auditing.

Upstream project: <https://github.com/cavanaug/siberia>

```bash
brew install cavanaug/tap/siberia
```

See `README.siberia.md`.
